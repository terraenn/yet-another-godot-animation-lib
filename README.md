<br>**How to use**:
1. Download the **.gd** file
2. Create a new AnimationHelper with AnimationHelper.create_animation_helper()
3. Call methods on the animation helper instance

<br>**Features:**
- Basic animation chaining
- Customizing default Tween.TransitionType, Tween.EaseType
- Flash, flash_color, pulse, pulse_scale, go_to animations (with documentation on them with examples)
